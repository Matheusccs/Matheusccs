### 👨🏾‍💻 Sobre Mim

Sou estudante de **Ciência da Computação** na UniRitter e atuo profissionalmente com **Suporte Helpdesk**, lidando diariamente com configurações de redes, gestão de servidores e resolução de problemas críticos. 

Estou em transição para a área de **Desenvolvimento de Software**, unindo a sólida base de infraestrutura e raciocínio lógico que já possuo ao desenvolvimento de aplicações web modernas, funcionais e escaláveis.

- 🔭 **Atualmente focado em:** Desenvolvimento Web FullStack (Node.js, React e JavaScript/TypeScript).
- ⚙️ **Diferencial:** Experiência prática com ambientes corporativos, servidores, redes e troubleshooting.
- 🎯 **Objetivo:** Contribuir em projetos desafiadores como Desenvolvedor Júnior / Trainee.
